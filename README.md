# Wifi Scanner

This project scans nearby electronic devices. It retrieves essential information such as MAC address, signal strength and time, providing the information of nearby people flow.

## Features

- **Scan for Electronic Devices**: The tool scans for all nearby device.
- **Retrieve Network Information**: Provides MAC address, signal strength, time, and other relevant information.
- **Real-Time Updates**: Continuously updates available WiFi networks upon scanning.

## Getting Start

### Prerequisites

- `socket`
- `datetime`
- `pandas`

### Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/John1117/Wifi-Scanner.git
    ```
    
2. Install the dependencies using:
    ```bash
    cd Wifi-Scanner
    pip install -r requirements.txt
    ```
### Usage
```bash
python main.py
```
